# ECC + skille — auto-routing (bez potrzeby jawnego wywoływania)

Zawsze stosuj poniższe automatycznie, gdy zadanie pasuje — NIE czekaj, aż użytkownik napisze "użyj skilla X":

- **UI / frontend / landing / komponent / redesign / styl / animacja** → od razu użyj skilla
  `ui-ux-pro-max` (jedyna główna — `impeccable`/`frontend-design` tylko na jawne żądanie, nie auto).
  Motion/animacje → dołóż `design-motion-principles`.
- **Opt-out:** gdy Mati powie „bez designu” / „plain” / „szybki hack” — pomiń auto-routing designu, zrób zwykłą, minimalną zmianę.
- **Reguły kodu**: przestrzegaj reguł z `~/.claude/rules/ecc/` (common + typescript + react + web + python).
- **Frontend = React/Next.js/TypeScript, backend/ML = Python.** Domyślny stack użytkownika.
